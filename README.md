## ✨ Features

- 🎨 **Grandeur dark UI** with neon purple/cyan accent palette
- 🌌 **100-particle canvas** with mouse attraction & connection lines
- 🖱️ **Custom cursor** with neon trail effect (12-dot trail)
- ⌨️ **Typewriter** cycling through 6 job titles
- 🪐 **Tech orbit animation** — 8 rotating tech badges
- 📊 **Animated skill bars** & circular SVG progress rings
- 🃏 **3D flip project cards** on hover
- 📜 **Certificate modal viewer** — click any cert to open PDF inline
- 📱 **Fully responsive** — mobile-friendly layout
- ⚡ **Zero dependencies** — pure vanilla JS
